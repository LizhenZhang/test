# Windows / WOA 每日舆情与体验简报（2026-09-14）

## 短摘要

9 月 8 日 Patch Tuesday 累积更新（24H2/25H2：`KB5124008`，构建 26100.9445 / 26200.9445；26H1：`KB5124012`，构建 28000.2954）的已知问题仍是当日主线。微软 Windows Release Health 截至 9 月 11 日仍列出三项有效问题：**USB Audio Class 1.0 无法启动或无声（Confirmed）**、**HCS/Plan9 主机文件夹共享失效（Confirmed，波及 WSL 与 Claude Cowork）**、**Remote Desktop Services 不稳定（Mitigated，正式修复待发）**。9 月 13 日媒体跟进确认 USB 音频问题无正式补丁，立体声回退仅为权宜之计。

WOA 侧：8 月 LCU 引发的 Arm64 Teams / 新 Outlook 启动失败已由 9 月 LCU 标 **Resolved**；Qualcomm Adreno 2026.08.2 仍提示 OS 26100.3915+ 外接显示器热插拔/改分辨率时部分游戏崩溃，需等微软系统修复。24H2 Home/Pro 将于 **2026-10-13** 停止更新。当日官方看板无新增条目；社区仍在报告 File History、AMD Radeon TDR、Always On VPN、VDI Explorer 崩溃等**尚未进入官方已知问题列表**的现象。未见与 CIX 板卡/整机交叉的新 WOA 评测。
